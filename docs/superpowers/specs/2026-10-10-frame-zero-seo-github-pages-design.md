# FRAME ZERO: SEO и подготовка к GitHub Pages

Дата: 2026-10-10

Публичный адрес: `https://kristina-timoshkina.github.io/frame-zero-portfolio/`

## Цель

Полностью закрыть учебное задание по AI-анализу лендинга, SEO-оптимизации, улучшению представления контента и синхронизации проекта с GitHub, не меняя утверждённый визуальный дизайн FRAME ZERO и светлой монтажной.

## Страницы и позиционирование

### Главная страница

- URL: `https://kristina-timoshkina.github.io/frame-zero-portfolio/`
- Основная тема: интерактивное портфолио режиссёра монтажа Евгения Тимошкина.
- Ключевые направления: видеомонтаж, трейлерный монтаж, VFX, цветокоррекция, звук, DaVinci Resolve Studio.
- Предлагаемый title: `Евгений Тимошкин — режиссёр монтажа | FRAME ZERO`.
- Описание должно кратко перечислять направления работы и подчёркивать интерактивный формат портфолио.

### Монтажная

- URL: `https://kristina-timoshkina.github.io/frame-zero-portfolio/montage/`
- Основная тема: кейс монтажа короткометражного фильма «Накладно».
- Предлагаемый title: `Монтаж фильма «Накладно» — кейс Евгения Тимошкина | FRAME ZERO`.
- Описание должно отражать работу с исходниками, отбором дублей, таймлайном, цветом, звуком и трейлером.

## Метаданные

Для обеих страниц добавляются:

- уникальные `title` и `meta description`;
- `meta robots` со значениями `index, follow, max-image-preview:large`;
- абсолютный `canonical`;
- Open Graph: title, description, type, locale, site name, URL, image, размеры и alt изображения;
- Twitter Card `summary_large_image` с отдельными title, description и image alt;
- согласованный `theme-color` и favicon.

Существующее изображение `og-frame-zero.png` размером 1200 × 630 используется как корректное социальное превью обеих страниц. Новые растровые изображения не генерируются, поскольку в проекте уже есть полноценная обложка и тематические кадры.

## Структурированные данные

Главная страница получает JSON-LD `@graph`:

- `Person` — Евгений Тимошкин, режиссёр монтажа;
- `WebSite` — FRAME ZERO, русский язык, автор Евгений Тимошкин;
- `ProfilePage` — портфолио и основные направления работы.

Монтажная получает JSON-LD:

- `CreativeWork` — монтажный кейс короткометражного фильма «Накладно»;
- автор и монтажёр связываются с сущностью `Person` через стабильный `@id` главной страницы;
- данные описывают только реально видимый материал и не содержат неподтверждённых наград, рейтингов или дат.

## Индексация

Добавляются:

- `public/robots.txt` с разрешённым обходом и абсолютной ссылкой на sitemap;
- `public/sitemap.xml` с главной страницей и монтажной;
- дата `lastmod` — 2026-10-10;
- доступная текстовая структура и семантический H1 для монтажной;
- стандартные crawlable-ссылки между главной и монтажной сохраняются.

## Изображения и медиа

- Проверяются существующие alt-тексты и декоративные изображения.
- OG-изображение остаётся 1200 × 630.
- Видео главной продолжают использовать `preload="none"` и загружаются только при необходимости.
- Трейлер монтажной продолжает создаваться только после действия пользователя и использует `preload="metadata"`.
- Полный фильм не должен загружаться при первом открытии монтажной.
- Неиспользуемые исходные файлы не удаляются без отдельного согласования.

## GitHub Pages

- Сохраняется относительная Vite-база `./`, совместимая с подпапкой репозитория.
- Проверяется production build и обе итоговые HTML-страницы в `dist`.
- Существующий workflow `.github/workflows/deploy-pages.yml` продолжает публиковать `dist` после изменений в `main`.
- Работа сначала отправляется в ветку `homework-2-improvements`.
- Для публикации рекомендуется pull request в `main`, чтобы изменения можно было просмотреть перед запуском GitHub Pages.

## Проверка

- `npm run build` без ошибок;
- корректные относительные пути в production build;
- главная и `/montage/` открываются напрямую;
- canonical, OG, Twitter и JSON-LD присутствуют в собранных HTML;
- `robots.txt` и `sitemap.xml` попадают в `dist`;
- переход FRAME ZERO → монтажная → FRAME ZERO работает;
- в консоли браузера нет ошибок;
- тяжёлые видео не запрашиваются до соответствующего действия пользователя.

## Вне текущего этапа

- покупка собственного домена;
- подключение Google Search Console после публикации;
- добавление контактов или социальных профилей, которых пользователь не предоставлял;
- удаление архивных исходников и резервных копий.
