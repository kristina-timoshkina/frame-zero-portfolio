# FRAME ZERO — обновление представления на GitHub

## Цель

Синхронизировать публичное оформление GitHub-репозитория с уже опубликованной финальной версией FRAME ZERO. Работа не меняет интерфейс или поведение сайта.

## Утверждённый подход

Используется точное изображение опубликованной страницы, а не заново нарисованный макет. Так в README будут видны актуальные глаз-буква `O`, подпись `Монтажная` и текущая композиция первого экрана.

Для социальных сетей создаётся отдельное превью размером `1200 × 630`. Оно сохраняет фирменную композицию первого экрана, но кадрируется под Open Graph без мелких элементов, которые плохо читаются в Telegram и VK. Файл получает новое имя `og-frame-zero-v2.png`, чтобы уменьшить влияние старого кэша.

Альтернативы, от которых отказались:

- оставить старое изображение — оно больше не соответствует сайту;
- использовать один и тот же полный скриншот для README и соцсетей — формат полного экрана плохо подходит к пропорции `1200 × 630`;
- генерировать новое изображение нейросетью — это исказило бы точную типографику и утверждённый интерфейс.

## Изменения

1. Заменить `screenshots/frame-zero-home.png` свежим скриншотом опубликованного первого экрана.
2. Добавить `public/og-frame-zero-v2.png` и использовать его в Open Graph и Twitter Card главной страницы и монтажной.
3. Обновить README: убрать формулировку «одностраничный», описать две связанные части сайта и оставить актуальную ссылку на демо.
4. Обновить GitHub About: убрать ошибочное упоминание React и указать JavaScript, Three.js, GSAP и Vite.
5. Обновить Topics: удалить `react`, добавить `javascript`, `threejs`, `gsap`, `github-pages`, `video-portfolio`.
6. Использовать новое изображение как GitHub Social preview, если GitHub позволяет изменить его через текущую авторизованную сессию.

## Проверка

- README отображает свежий первый экран;
- размеры Open Graph изображения равны `1200 × 630`;
- главная и монтажная ссылаются на `og-frame-zero-v2.png`;
- production-сборка проходит;
- опубликованный сайт не меняет внешний вид и поведение;
- описание и темы репозитория соответствуют фактическому стеку.

## Границы

- Исходные видео и архивы не изменяются.
- Дизайн FRAME ZERO и монтажной не перерабатывается.
- Обновляются только публичные материалы представления проекта на GitHub и в социальных превью.
