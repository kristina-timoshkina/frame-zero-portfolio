# План обновления GitHub-превью FRAME ZERO

1. Снять актуальный первый экран опубликованного сайта в desktop-размере.
2. Заменить README-скриншот и подготовить отдельный Open Graph кадр `1200 × 630`.
3. Обновить ссылки Open Graph и Twitter Card на новое имя файла.
4. Исправить README: описать главную FRAME ZERO и монтажную «Накладно» как две связанные страницы.
5. Собрать проект и проверить размеры изображений и HTML-метаданные.
6. Обновить GitHub About и Topics через GitHub API или авторизованный интерфейс.
7. Отправить ветку в GitHub и создать pull request.
