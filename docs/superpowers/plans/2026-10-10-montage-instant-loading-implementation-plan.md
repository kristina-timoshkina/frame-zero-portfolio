# Montage Instant Loading Implementation Plan

**Goal:** Ускорить первый и повторный вход из FRAME ZERO в монтажную, не меняя утверждённый дизайн и не включая видео в первоначальную загрузку.

**Architecture:** Главная страница незаметно прогревает HTML монтажной и критические изображения после своей первичной отрисовки, а наведение/фокус/касание O повышает срочность прогрева. Монтажная использует облегчённые AVIF-копии с автоматическим JPG-fallback, проявляет готовые изображения без скачков и заранее готовит следующий зал. Трейлер и полный фильм остаются ленивыми.

**Tech Stack:** Vite, vanilla JavaScript, CSS, HTML, AVIF/JPEG assets, existing MP4 assets.

---

### Task 1: Подготовить облегчённые изображения

**Files:**
- Create: `public/montage/media/*.avif`
- Preserve: `public/montage/media/*.jpg`

- [ ] Создать AVIF-версии всех статичных изображений монтажной с качеством, визуально не отличимым в размерах экранов сайта.
- [ ] Сравнить размеры исходников и новых файлов; не заменять и не удалять JPG.
- [ ] Проверить размеры и декодирование нескольких критических файлов.

### Task 2: Прогреть монтажную из FRAME ZERO

**Files:**
- Modify: `src/main.js`
- Modify: `src/styles/motion.css`

- [ ] После загрузки главного экрана в idle-режиме запросить HTML монтажной, фон комнаты и изображения первого зала.
- [ ] Запускать/продвигать прогрев при `pointerenter`, `focusin` и `touchstart` на входе O.
- [ ] Не ждать окончания прогрева при клике и не блокировать переход.
- [ ] Сократить эффект входа и задержку навигации до 360–400 мс, сохранив reduced-motion.

### Task 3: Добавить устойчивую загрузку изображений в монтажной

**Files:**
- Modify: `montage/index.html`

- [ ] Загружать AVIF как основной формат и один раз переключаться на исходный JPG при ошибке.
- [ ] Фону комнаты задать высокий приоритет, асинхронное декодирование и устойчивые размеры.
- [ ] Мониторным изображениям добавить состояние мягкого проявления и нейтральное свечение до готовности.
- [ ] После отображения текущего зала предзагружать следующий, затем остальные статичные изображения с низким приоритетом.
- [ ] Не менять ленивую загрузку трейлера и полного фильма.
