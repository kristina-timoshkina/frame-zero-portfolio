# План реализации: финальная полировка FRAME ZERO

## 1. Контактный финал

- В `src/app/AppShell.js` заменить вторичное действие финального экрана на семантический контактный блок.
- Добавить четыре явные ссылки: портфолио, Telegram, e-mail, VK.
- Использовать новые вкладки только для внешних веб-ссылок; `mailto:` оставить обычной ссылкой.
- В `src/styles/components.css` оформить блок как компактные «финальные титры», добавить hover/focus и одноколоночную мобильную версию.

## 2. Нагрузка главной 3D-сцены

- В `src/three/SceneCanvas.js` определить профиль качества из ширины экрана, `devicePixelRatio`, `navigator.hardwareConcurrency` и reduced motion.
- Уменьшить частоту кадров, разрешение, плотность частиц, multisampling и bloom только для низкого профиля.
- Вне hero прекратить анимационный цикл после затухания, сохранив статичный кадр, если сцена ещё видима в композиции.
- Сохранить нынешнюю high-quality сцену на современных desktop-устройствах и существующую паузу при проигрывании видео/скрытой вкладке.

## 3. Доступность

- В `src/components/MediaFrame.js` включить видимый текст PLAY в доступное имя видео-кнопки.
- В `src/app/AppShell.js` и `montage/index.html` согласовать доступные имена с видимыми подписями «Монтажная» и «Завершить монтаж».
- В `montage/index.html` применять `inert` к закрытому viewer, чтобы его кнопка не была доступна через Tab.
- В `src/styles/components.css` увеличить интерактивную область кнопок звука без визуального увеличения самого знака.

## 4. Медиа и очистка

- Проверить все `.m4v` в `public/media/clips` на отсутствие ссылок и совпадение с `.mp4` по содержимому.
- Удалить только подтверждённые дубликаты, затем проверить `git diff --check` и сборку.
- Не перекодировать видео повторно: они уже загружаются отложенно, а риск деградации качества выше потенциальной выгоды.

## 5. Проверка

- Запустить `npm run build`.
- Проверить desktop и mobile в Playwright: контакты, доступ с клавиатуры, hover/focus, переход FRAME ZERO → монтажная → FRAME ZERO, четыре зала, трейлер и полный фильм.
- Убедиться, что закрытый viewer не попадает в tab-order, нет console errors, а MP4 монтажной не запрашиваются до действия пользователя.
- Запустить Lighthouse production preview для главной и монтажной, сравнить результаты с текущей базой.
- Зафиксировать изменения отдельным коммитом, отправить ветку и создать pull request.
