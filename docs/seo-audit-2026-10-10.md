# AI-аудит и SEO-оптимизация FRAME ZERO

Дата: 2026-10-10
Публичный адрес: <https://kristina-timoshkina.github.io/frame-zero-portfolio/>

## Цель анализа

Проверить, что интерактивный лендинг понятно представлен поисковым системам и социальным сетям, быстро открывается, содержит доступные описания медиаматериалов и корректно публикуется в подпапке GitHub Pages.

## Что было найдено

### Метаданные

- На главной странице уже были базовые title, description и Open Graph image.
- Не было canonical URL, robots meta, Twitter Card, полного набора Open Graph и структурированных данных.
- У монтажной не было собственного SEO-описания, canonical URL, favicon и социального превью.

### Индексация

- В проекте отсутствовали sitemap и robots.txt.
- Монтажная являлась отдельной HTML-страницей, но не была описана как отдельный поисковый документ.
- Основное содержание главной создаётся JavaScript. Для режима без JavaScript отсутствовало текстовое описание и ссылка на монтажную.

### Семантика и доступность

- Главная имела один логичный H1 и последовательные H2.
- У монтажной не было семантического H1, хотя визуально страница имела собственную тему.
- Основные видео, кнопки и изображения уже имели доступные подписи; декоративные миниатюры были корректно оставлены с пустым alt.

### Скорость

- Видео главной используют `preload="none"` и не должны загружаться одновременно со стартовым экраном.
- Трейлер монтажной создаётся только после действия пользователя и использует `preload="metadata"`.
- Полный фильм весит около 18 МБ, поэтому его нельзя загружать при первом открытии страницы.
- Основной 3D-чанк после production-сборки весит около 150 КБ gzip. Он оправдан интерактивной сценой, но должен оставаться лениво подключаемым.
- OG-обложка имеет рекомендованный для социальных карточек размер 1200 × 630.

## Что улучшено

- Созданы уникальные title и description для главной и монтажной.
- Добавлены абсолютные canonical URL для GitHub Pages.
- Добавлены robots meta, Open Graph и Twitter Card.
- Добавлены JSON-LD сущности `Person`, `WebSite`, `ProfilePage`, `CreativeWork` и `BreadcrumbList`.
- Созданы `public/robots.txt` и `public/sitemap.xml`.
- В sitemap включены главная и монтажная.
- Монтажная получила доступный H1.
- Для режима без JavaScript добавлено краткое описание портфолио и ссылка на кейс «Накладно».
- README обновлён с учётом монтажной, SEO и фактически используемых технологий.

## Что сознательно не менялось

- Утверждённый дизайн FRAME ZERO и монтажной.
- Видео и изображения проекта.
- Неиспользуемые исходники и резервные копии не удалялись.
- Не добавлялись неподтверждённые контакты, социальные профили, рейтинги, награды или даты фильма.

## Проверка

- JSON-LD успешно проходит синтаксический JSON-парсинг.
- Sitemap успешно проходит XML-проверку.
- Production-сборка создаёт обе HTML-страницы.
- В `dist` присутствуют `robots.txt` и `sitemap.xml`.
- Canonical, Open Graph, Twitter Card и JSON-LD присутствуют в собранных HTML.

## Следующие действия после публикации

1. Проверить опубликованные URL главной и монтажной.
2. Проверить социальное превью по публичному адресу.
3. При необходимости подключить Google Search Console и отправить sitemap вручную.
4. Следить за Core Web Vitals на реальном хостинге; локальные показатели не отражают скорость сети посетителя.
